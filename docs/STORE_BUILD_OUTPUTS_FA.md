# خروجی‌های انتشار فروشگاهی متنویس

## قالب‌های اندروید
- APK: بسته نصب اندروید؛ قالب اصلی تست مستقیم و قالب رایج بارگذاری در فروشگاه‌های اندرویدی.
- AAB: قالب Android App Bundle؛ فقط در صورتی بارگذاری شود که پنل فروشگاه برای برنامه شما آن را درخواست یا پشتیبانی کند.
- BIN: پسوند استاندارد بسته نصب اندروید نیست. فایل APK را نباید با تغییر نام به BIN تبدیل کرد. اگر پنل کافه‌بازار فایل BIN می‌خواهد، باید مشخصات دقیق همان فیلد/فرآیند بررسی شود.

## امضای نسخه انتشار
برای امضای Release این GitHub Secrets را تعریف کنید:
- `ANDROID_KEYSTORE_BASE64`: محتوای فایل keystore به صورت Base64
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

فایل keystore و رمزها نباید commit شوند. تا وقتی این Secrets تنظیم نشده‌اند، خروجی Release امضاشده قابل تولید نیست.

## خروجی تست
Workflow خروجی Debug APK و گزارش تست را به صورت GitHub Actions Artifact منتشر می‌کند. خروجی Debug برای تست داخلی است و جایگزین نسخه Release امضاشده فروشگاهی نیست.
